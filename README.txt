GCR TRAINS - OFFLINE TRAIN TIMETABLE WEBSITE
============================================

QUICK START (WINDOWS)
1. Extract the ZIP folder anywhere on your computer.
2. Double-click START_GCR_TRAINS.bat (or double-click index.html).
3. Your default browser opens the GCR Trains site, even without Internet.

Alternatively, download the standalone HTML file, then simply double-click it.

WHAT YOU CAN DO
- Register one-off or repeating train services.
- Add passenger, freight, ECS, engineering and other trains.
- Use headcodes, operator names, traction, formations and notes.
- Build a timetable with as many intermediate timing points as required.
- Choose from all 100 locations in Headcode Planning (76 station/junction,
  24 yards/depot/sidings) including full name, 3-letter code and TIPLOC.
- Search by date, location, destination, headcode, service type, STP status.
- Inspect detailed timetable, then enter actual running times manually.
- Edit, duplicate and delete registered services.
- Export CSV, back up as JSON, and restore a JSON backup.

WHERE YOUR TRAINS ARE SAVED
Your data is saved in local browser storage for this site, on your computer.
It is NOT automatically saved to Google Sheets or Roblox. Keep the website
in the same location and use the same browser profile to retain its data.
Do not use your browser's incognito/private mode. Clearing site data may
remove saved services.

IMPORTANT: Choose "Data & backup" > "Download JSON" regularly so you have
an independent copy of all timetables and manual reports. Restoring is done
from the same screen, using "Import JSON".

DATA & LIMITATIONS
This version is fully offline and requires no Python, Node.js, hosting, or
network connection. It does NOT have an automatic Roblox integration, so
running status and actual times are entered manually. It is not affiliated
with the real Realtime Trains website.

Locations/headcodes: "Headcode Planning" in the Google Sheet supplied by the
user: https://docs.google.com/spreadsheets/d/1uI9NQ5uf1RKdUgtc1b2VqdiF7WaqM2ZUrjm-coMUNaA/edit?gid=1789049803

Note: Some three-letter codes (notably STM and SCS) are used for multiple
locations. The site preserves them all and differentiates them by TIPLOC.
When registering a service, choose the full location name in those cases.

COMPATIBILITY
Designed for up-to-date Chrome, Edge, or Firefox on Windows. The bundled
site works with standard HTML, CSS and JavaScript; no dependencies or installs.
